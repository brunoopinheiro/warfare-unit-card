# Warfare Unit Card

This project was made to easy the process of filling and creating unit cards to the Kingdoms & Warfare TTRPG supplement made by MDCM.


## Utilized Stacks

This is a front-end only project, made mostly with React and native CSS, built with Vite.


## Running Locally

```bash
npm ci          # install exact versions from package-lock.json (install scripts are disabled via .npmrc)
npm run dev     # start the dev server at http://localhost:5173
npm run build   # production build into ./build
npm run preview # serve the production build locally
```
